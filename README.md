# 自分探検

外部API・外部ライブラリを使わない、スマートフォン向けの静的Webアプリです。

## 次の開発段階：AI接続

UIはFigmaで設計する方針に切り替え、現在の画面は固定質問の体験版として維持しています。別途 `worker/` にGemini接続API、`lib/scene-api.mjs` にUIに依存しないクライアントを追加しました。**現在の画面から外部AIへの送信は行いません。**

接続設定・Figma側とのAPI契約・未課金サービスのデータ利用上の課題は [docs/ai-integration.md](docs/ai-integration.md) を参照してください。AIは既定で無効、キー未登録、未デプロイです。実サービスとの疎通・会話品質検証は未実施です。

Node.js 20以降で `node --test tests/ai.test.mjs` を実行すると、外部通信をモックした15件のAPI・終了判定・引用照合・利用制限・エラー・クライアントのテストが動きます。WranglerやGeminiキーはこのテストには不要です。

## 実行方法

`index.html` をブラウザで開いてください。ビルド・インストールは不要です。localStorageの挙動はブラウザの設定や、ファイルを直接開く場合の実装によって異なります。保存・再開の安定した確認には、任意の静的HTTPサーバーでこのフォルダを配信してください（Pythonがある場合は `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます）。Cloudflare Pagesでもこのフォルダを静的ファイルとして配信できます。

## 機能

- ウェルカム画面から開始し、過去・現在・未来それぞれ2問、計6問に回答
- 回答したくない質問のスキップ、空欄送信の防止、回答は各2000文字まで
- 回答・進行位置・入力途中の文章をlocalStorageへ自動保存し、再読み込み時に再開
- 終了後は本人の言葉のかけらが現れる完了画面と、タップしてひらく6枚の景色カードを表示（スキップは余白として表示）
- 確認ダイアログからこのアプリの記録だけを削除
- 保存不可・容量超過・壊れた保存データを画面上で通知

## ファイル

- `index.html`: 各画面と削除確認ダイアログ
- `styles.css`: スマートフォン優先のレイアウトと景色の装飾
- `app.js`: 固定質問、画面遷移、保存・再開、カード、削除処理

ログイン、AI、解析ツール、外部通信はありません。記録はブラウザのオリジンごとに保存され、別端末・別ブラウザへ同期されません。共用端末では削除してください。ブラウザのデータ消去でも記録は失われます。本MVPは診断や心理的な助言を提供しません。

## 開発時の動作確認

`verify.cjs` は開発用の任意のブラウザ確認スクリプトです。アプリの実行には不要です。既存のPlaywrightがある環境で `node verify.cjs` を実行できます。別の場所にあるPlaywrightを使う場合は環境変数 `PLAYWRIGHT_PATH` にモジュールのパス、既存のChromeなどを使う場合は `BROWSER_PATH` に実行ファイルのパスを指定します。プロジェクトにライブラリは追加していません。

実際のChromeで開始、書きかけ保存、途中再開、空欄送信防止、スキップ、6問完了、回答の安全な文字表示、カード再表示、削除の取消・実行、他の保存データの保持、破損データ・保存失敗の通知を確認済みです。320・375・768・1280px幅で結果画面に横スクロールが発生しないことを確認しました。検証環境の通信制限に合わせ、ブラウザにはローカルの実ファイルをリクエスト差し替えで配信しています。

## 現在の体験範囲

2パート構成のうち「PART 01 景色を集める」を実装しています。固定質問によるメッセージ形式で、送受信時のアニメーションと最新メッセージへの自動スクロールがあります。「PART 02 景色をつなぐ」は今後の予定の案内のみで、分析・つながりの解釈・完成地図の生成は行いません。完了画面の短い言葉は本人の回答の冒頭を表示し、省略時は「…」を付けます。カードを開くと回答全文を読めます。

## トップページの挿絵

`assets/exploration-hero.png` は内蔵の画像生成ツールで制作した水彩調の挿絵です。アプリの実行時に画像生成APIは使いません。生成指示は `assets/hero-prompt.md` に保存しています。トップは紙色・森の挿絵・3つの紹介・金色の開始ボタンで構成しています。紹介の後半2つは今後の予定として明示しています。

## チャットの見た目

トップと同じ紙色を背景に、案内の吹き出しは淡い金色、本人の言葉は白で表示します。`assets/lantern.svg` と `assets/navigator.svg` はローカルのUIアイコンです。右側に「集めた景色」「設定」「使い方」があり、キーボード表示中は隠して会話の幅を確保します。入力枠を金色に変更し、既存のスクロール制御を維持しています。
