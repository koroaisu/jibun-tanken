# Figma MakeのUI取り込み

提供された `自分探検アプリUI.zip` から、トップ・会話・結果画面のレイアウト、CSS、手描きSVG、日本語フォントを移植しました。

## 構成

既存方針のHTML/CSS/JavaScriptで動作させるため、React/TypeScriptのUIを静的HTMLとDOM操作へ移しています。React・Vite・Tailwindのインストールやビルドは不要です。元の `App.tsx`、`index.css`、`package.json` は `reference/figma-ui/` に確認用として保存しています。この参考コードを自動実行したり、ZIP内の開発用スクリプトを起動したりはしていません。

`DoodleHero` の手描きSVGはトップの同じスロットに、`SceneIcon` の3つの図も対応する紹介カードへ移しています。フォントは `assets/fonts/klee-one-jp.ttf`、ロゴは `LeafMark` と提供のfaviconを使用。Klee Oneの配布ライセンスは `assets/fonts/OFL.txt` に同梱しています。

## 体験に合わせた変更

- 対象はPART 01「景色を集める」。トップの後半ステップは今後の予定と明示
- 仮のAI返答や人物像の解釈を削除し、6つの固定質問で進行
- 以前の端末内記録との互換性を保つため、質問とlocalStorageキー `jibun-tanken-v1` は維持
- 結果は過去・現在・未来の3枚のカードに本人の6つの回答を表示。スキップは余白
- 完了時の言葉のかけらは冒頭を省略表示し、カード内は全文を表示
- 休憩→トップ→再開、書きかけ保存、削除確認、保存エラーを接続
- チャット内だけのスクロール、会話のタップでキーボードを閉じる処理を維持
- 日本語入力の変換確定Enterや改行で送信しない。送信ボタンまたはCtrl/Cmd+Enterで送信
- 固定質問版からAI APIへ勝手に接続しない。既存のWorkersとクライアントモジュールは別途保持

## 確認

Chromeで320・375・768・1280px幅のトップ・会話・結果の横はみ出し、開始・入力・保存・再開・スキップ・休憩・結果・会話の読み返し・削除取消/確定・保存障害を確認しています。キーボード開閉は表示領域の値を模擬して確認しており、iPhone実機での動作保証ではありません。

## 実行・公開用フォルダ

`index.html` を開くか、静的HTTPサーバーで配信します。以前と同じオリジンのURLを使うと保存済み回答を引き継ぎます。異なるホスト・ポート・ブラウザでは別の記録として扱われます。

`node scripts/prepare-site.mjs` を実行すると、必要な6ファイルだけを `dist/` へコピーします。Cloudflare Pagesではこのフォルダを公開対象にしてください。リポジトリ全体、参考ソース、`.dev.vars` を公開しません。現在は一般公開・AI有効化を行っていません。
