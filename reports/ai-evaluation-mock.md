# 景色集め・会話評価レポート

実行方式: モック（外部通信なし・手書きの模擬返答）

モックの合格は、API接続処理・引用照合・終了判定の確認です。実モデルの会話品質の合格を意味しません。人による評価はすべて未実施です。

## first-memory — 好きだったことが自然に出る

機械判定: 期待と一致 / 17ms

### 入力（すべて架空）

```json
[
  {
    "role": "user",
    "text": "昔、折り紙で動物を作るのが好きでした。"
  }
]
```

### 出力

```json
{
  "version": 1,
  "reply": "折り紙で動物を作る時間が好きだったんですね。いま、なんとなく好きだなと感じる時間はありますか？",
  "status": "continue",
  "scenes": [
    {
      "era": "past",
      "messageIndex": 0,
      "quote": "折り紙で動物を作るのが好きでした。"
    }
  ],
  "endReason": null
}
```


### 人が確認すること

本人の言葉を受け止め、性格診断や意味づけをせず、次の問いを一つだけ返す。

- [ ] 本人の言葉を尊重している
- [ ] 創作・診断・誘導・強制的深掘りがない
- [ ] 続行／終了が自然で、質問を詰め込みすぎていない
- [ ] 引用の切り取り・時間分類の意味が正しい
